## 最新续接结果

### 正式比赛日志开关

新增 `-debug=false`，以及启动脚本的 `AGENT_DEBUG=false`。关闭时禁用完整回放文件、逐回合/启动摘要，并跳过日志专用拷贝和摘要计算；保留警告/错误。默认 true，兼容原调试方式。

Windows/Linux 二进制已更新，本次冻结包在 `iteration/releases/20260915-064127-9a29a53a/`。单测、vet、服务/记录模块 Linux race 检测通过。真实 Linux 服务开关对比证据位于 `iteration/validation/debug-on/` 和 `iteration/validation/debug-off/`：样例响应 SHA-256 完全一致；开启时写入两条记录，关闭时无日志目录；关闭时注入的无效 JSON 仍输出错误警告。两种模式的幂等与 SIGTERM 退出均通过。

以下结果更新早期记录中的未完成状态：

- Ubuntu/WSL 已配置 Go 1.24.1 和 gcc，全部包 `go test -race ./... -count=1` 通过。
- Linux 发布包真实启动、HTTP 200、重复请求幂等、SIGTERM 正常退出及日志刷新通过；重放响应/Memory 差异均为 0。
- 增补经济、建造、升级、夜间战斗、冷却、任务、宝藏、移动冲突和两个半场 2600 回合的合成快照测试。游戏模块覆盖率达到 76.6%，服务模块 79.1%；合成序列不等于官方比赛。
- 修复控制者 ID 非标准拼写可绕过互斥检查、炮塔建造缺失最终连通性检查；加入负坐标配置拒绝与正式地图预检。
- 新增发布包白名单冻结、候选流程状态机、外部适配器进程契约和自动日志复盘；超时恢复、错版本、编译失败、日志异常、预算、并发锁及实际适配器子进程契约已测试。

## 基准采样

CPU：Intel Core i5-12450H；Windows amd64；每项仅 3 次采样。

| 项目 | 平均耗时 | 分配量 |
| --- | ---: | ---: |
| 41×32 空地图三角色联合寻路 | 约 4.39 ms/op | 约 6.03 MB/op |
| 文档请求样例整轮决策 | 约 19.90 ms/op | 约 24.53 MB/op |

这些数值在第一轮集成后采集，之后修复了建造占格和任务状态等边界；不是最终版本在全部场景的性能承诺，也不是 P99。大量分配仍有优化空间；复杂拥堵和极端长输入需要官方真实日志压力测试。
