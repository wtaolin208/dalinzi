# 积分收益策略

实现集中在 `internal/game/strategy.go`，由任务选点、技能学习、回防和战斗评分调用。所有预测均为启发式估算，不代表判题器会按预测推进。

## 任务收益与调度

完整完成积分使用 `B + 5*T/d`。选点按成功概率计算预期积分，再加入金币的边际价值，除以移动、接取、预计解题和不可利用的冷却时间。

- 领取前看不到题目，因此按任务点统计推测：初始耗时 8 回合、成功概率 65%，用两个虚拟历史样本平滑后续观测。明确的提交成功/失败及未提交而结束的任务会影响统计；断档或缺少反馈不推断成功。
- 在同一任务点有可用学习技能时，按 50% 机会走 3 回合快速流程估计耗时；不假定下一题一定匹配。
- 未完全正确时的通过率没有数值字段，暂用 25% 作为部分完成先验。金币不视为积分：低于储备目标时每金币效用权重为 0.5，否则 0.1。
- 单点冷却为 30 回合；存在其他可达且可用/冷却中的点时，按其预计剩余等待减少冷却成本，支持交替做任务。并不假定任务点无限刷新。
- 只在白天接任务；预计移动、解题、回防及 `returnBuffer` 之和必须小于白天剩余回合，也必须能在半场结束前完成。任务超时不足时不接。
- `Trace.tasks` 展示预计耗时、成功率、预期积分、返回距离、冷却等待、安全判断和综合价值。

## 学习回本

学习的即时积分损失：`5*T*(1/d - 1/(d+extra))`。随答案直接提供技能候选需要一次验证往返；单独提炼再验证需要两次往返，按各自成本判断。

预计复用收益以同类任务从当前估计耗时缩短到 3 回合计算。协议没有剩余任务数，使用剩余比赛时间估计机会，最多三个机会、每个机会乘 60% 的同类概率先验。只有预计收益超过本题损失且留有时间才学习。已有匹配技能、基地危险、夜晚、超时字段缺失或白天余量不足时不学习。

`Trace.learning` 记录即时损失、预计复用次数、未来收益与是否值得学习。第一次验证只覆盖原题，后续依然可能失败并被停用。

## 任务退出与回防

- 基地五格范围内存在未眩晕机器人，且基地血量不超过 400，或这些机器人的三次攻击估算达到基地当前血量时，判为紧急危险。使用机器人类型的规则攻击力，不模拟完整战场。
- 进行中的任务若已经进入夜晚，或预计剩余解题时间加返程和缓冲不足，会释放开拓者回防；没有任何基地/武器数据时不凭空推断回防地点。
- 放弃标记持续到任务结束，清除待处理的模型/技能验证，解除联合寻路中的任务锁定，选择任务区外的防守位置。若防守位置与任务区重叠，先离开任务区。真实移动仍受地形、队友和敌方碰撞影响。
- 紧急退出期间不让开拓者被炮台操作指令再次锁住；原地受阻时沿用现有下一步风险与绕行策略。不存在可达出口时，无法保证当回合退出。

这优先保护生存，可能放弃仍可拿分的任务；危险阈值和估时需实战校准。

## 临近天亮的火力价值

夜晚最后六回合逐步降低无法在当前攻击组合中击杀的伤害价值，最后一回合其值为零。完成击杀仍计入伤害、击杀奖励和威胁权重。战斗的候选生成和组合选择共同使用此评分，避免在机器人即将被清除前无效刷伤害。

这是对当前攻击组合的评价，不是跨多个未来回合的完整战斗搜索。

## 验证

`strategy_test.go` 验证速度奖励、历史失败、金币价值、双点冷却、回防时间、学习成本算例、直接提交、真实策略入口下的紧急退出，以及天亮前击杀优先。测试使用合成状态，不表示已获得官方对战收益数据。
